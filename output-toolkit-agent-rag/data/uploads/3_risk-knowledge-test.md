# 风控业务知识手册（测试文档）

## 一、支付风控基础概念

风控系统的核心目标是在保障用户体验的前提下，识别并拦截欺诈交易。常见的风险类型包括：盗卡盗刷、套现、洗钱、羊毛党薅羊毛、账户盗用等。

### 1.1 风险评分

每笔交易会经过风控引擎计算风险评分（0-100分）：
- 0-30 分：低风险，直接放行
- 31-70 分：中风险，触发短信验证或人脸识别
- 71-100 分：高风险，直接拦截并转人工审核

### 1.2 设备指纹

设备指纹通过采集设备的硬件信息、系统配置、浏览器特征等生成唯一标识。同一设备绑定超过 3 个账户时，会触发设备聚集预警。

## 二、常见风控规则说明

### 2.1 交易限额规则

- 单笔限额：普通用户单笔交易不超过 5 万元
- 日累计限额：普通用户日累计不超过 20 万元
- 未实名用户：单笔不超过 1000 元，日累计不超过 5000 元

### 2.2 套现识别规则

以下特征组合会命中套现模型：
1. 新入网商户 + 大额整数交易
2. 同一批用户在同一商户高频交易
3. 交易时间集中在凌晨
4. 用户使用代理 IP 或机房 IP

## 三、工单处理流程

### 3.1 风险工单分级

- P0：资金损失类工单，30 分钟内必须响应
- P1：账户冻结申诉类工单，2 小时内响应
- P2：一般咨询类工单，24 小时内响应

### 3.2 账户解冻流程

用户账户因风控被冻结后，解冻流程如下：
1. 用户提交身份证明材料和交易说明
2. 风控专员核实材料真实性（1个工作日）
3. 核实通过后在风控后台执行解冻操作
4. 解冻结果短信通知用户
